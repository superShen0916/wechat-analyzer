# 会话数据与隐私

## 信任边界

聊天导出包含用户及第三方的高度敏感信息。`stats` 和本地报告生成不跨出本机；
`analyze` 调用配置的模型供应商时会跨越网络信任边界。该差异记录在
`README.md` 的 Privacy model 章节。

## 数据处理规则

- 除非用户明确要求导出，否则不要持久化第二份聊天原文。
- Fixtures、Snapshots、日志、示例和 Issue 中禁止出现真实聊天记录；使用
  `examples/sample-conversation.json` 作为合成数据范例。
- 新报告默认不包含原始消息；只有用户显式选择时才展示或导出正文。
- 任何向 LLM 发送内容的功能都必须允许用户预览发送范围、显式授权，并说明
  供应商边界。
- 派生 JSON 仍可能泄露身份和关系模式；移除标识及自由文本前不得宣称匿名。

## 时间数据

`loader.Message.CreateTime` 是 Unix 时间戳。转换位置和所用时区必须明确。
不得把自然日跨度与活跃天数混用为同一个指标。

## 报告安全

会话派生值必须经过 `html/template` 转义，不得对其使用 `template.HTML`。
报告保持完全自包含，避免远程字体、脚本、图片或统计服务在打开报告时泄露信息。

# Bootstrap：建立项目开发规范

## 背景

这是 `trellis init` 后自动创建的一次性任务。它负责把通用规范模板替换为从
`wechat-analyzer` 真实代码中提炼出的约定，使后续实现与检查 Agent 不需要依赖
聊天历史，也能遵循相同的工程规则。

## 目标

- 描述当前 Go CLI 的包边界和代码组织方式。
- 固化错误处理、终端输出、隐私和质量要求。
- 使用仓库内的真实文件和符号作为依据。
- 删除不适用于本项目的数据库等通用模板。
- 约定项目专属 Trellis 文档默认使用中文。

## 验收标准

- [x] `.trellis/spec/backend/` 不再包含占位文本。
- [x] 规范覆盖目录结构、错误处理、输出、质量和隐私。
- [x] 规范引用当前仓库中的真实实现或测试。
- [x] 不适用的数据库规范已删除。
- [x] `go test ./...` 与 `go vet ./...` 通过。
- [x] Trellis task validation 通过。

## 完成方式

通过提交确认后，归档该任务。此后 v0.2 等功能任务会按这些规范生成 PRD、
技术设计、实施计划和检查上下文。

# v0.2 关系动态分析

## 目标与用户价值

把当前以消息总量为主的报告升级为可解释的关系互动分析：用户不仅能看到“聊了
多少”，还能看到双方如何开始、回应和结束会话，以及这些行为随月份或两个时期
发生了什么变化。所有确定性指标在本地计算，结果可被终端、JSON 和离线 HTML
共同消费。

## 背景与已确认事实

- 当前 `stats.AnalyzeConversation` 直接遍历消息，计算总量、活跃日、小时和消息
  类型，尚无会话边界或响应行为模型（`internal/stats/analyzer.go:44`）。
- `MsgPerDay` 当前分母是活跃日数，不是记录跨度（
  `internal/stats/analyzer.go:95`），v0.2 必须明确区分口径。
- CLI 已支持单文件、目录和 HTML，但没有机器可读输出或时期对比命令（
  `cmd/main.go:73`）。
- HTML 是 `html/template` 生成的单文件，测试明确禁止外部 HTTP 资源（
  `internal/report/html_test.go:13`）。
- AI 画像改造、发送聊天正文和本地模型不属于本版本。

## 功能需求

### R1：稳定的消息时间线

- 分析前对消息副本按 `create_time` 升序稳定排序，不改变 Loader 返回的原切片。
- 相同时间戳保持输入顺序；所有日期和小时沿用运行机器的本地时区。
- 报告同时提供记录覆盖自然日数、活跃日数、自然日日均和活跃日日均。
- 保留已发布 JSON 字段 `msgs_per_day`，其现有“活跃日日均”语义不变，并新增
  名称明确的字段，避免破坏兼容性。

### R2：会话重建

- 默认相邻消息间隔超过 30 分钟时开启新会话；恰好 30 分钟仍属于同一会话。
- `stats`、`analyze` 和 `compare` 都支持 `--session-gap` 覆盖默认值。
- Gap 必须大于 0，非法值在 CLI 边界返回错误。
- 输出总会话数、平均每次会话消息数、最长会话消息数和最长会话时长。

### R3：双方互动指标

- 统计由“我”和“对方”分别开启、结束的会话数与比例。
- 连续同一方发送视为一个 Turn；只有说话方发生切换时才产生一次响应样本。
- 响应时长从上一 Turn 的最后一条消息到下一 Turn 的第一条消息计算。
- 分别输出“我的响应”和“对方响应”的样本数、中位数和 P90。
- 单消息会话可以同时由同一方开始和结束，但不产生响应样本。

### R4：活跃趋势

- 输出最长连续活跃天数。
- 按 `YYYY-MM` 输出排序稳定的月度统计：总消息、双方消息、会话数、活跃日数。
- 月度会话归属以会话第一条消息所在月份为准。

### R5：时期对比

- 新增 `compare <JSON 文件>` 命令，接收两个 `--period` 参数。
- Period 支持 `YYYY`、`YYYY-MM` 和 `YYYY-MM-DD..YYYY-MM-DD`，起止日期均包含。
- 每个时期输出消息量、会话数、双方开启会话比例、双方响应中位数和活跃天数，
  并给出第二时期相对第一时期的绝对变化；基线为零时不伪造百分比。
- 任一时期没有消息时返回清晰错误，不生成误导性结果。

### R6：多种输出

- `stats` 和 `compare` 增加 `--format text|json`，默认保持当前文本输出。
- JSON stdout 不得混入颜色或进度信息；批处理错误写入 stderr。
- 常规 HTML 报告展示会话概览、响应时间、主动性、连续活跃和月度趋势，且继续
  保持单文件、无外部请求。
- AI HTML 报告继续复用同一组关系动态指标。

### R7：隐私安全默认值

- v0.2 HTML 默认不再嵌入最长消息原文。
- 新增 `--include-content` 显式恢复最长消息展示；README 必须说明分享风险。
- JSON 默认只包含统计派生值，不包含 `TopMessages.Content`；只有显式选择内容
  输出时才允许包含。

## 验收标准

- [ ] 乱序消息可得到与排序输入相同的关系指标，原输入切片未被修改。
- [ ] 默认 30 分钟边界、等于边界及超过边界均有单元测试。
- [ ] 连续同方消息只形成一个 Turn，双方 P50/P90 有确定性测试。
- [ ] 自然日、活跃日、最长连续活跃和跨月会话均有边界测试。
- [ ] `stats --format json` 输出可被标准 JSON Decoder 直接解析且无额外文本。
- [ ] `compare` 支持三种 Period 格式并拒绝反向、重叠不受限但独立计算。
- [ ] HTML 包含 v0.2 关系指标，不包含外链；默认不包含消息原文。
- [ ] `--include-content` 时才在 HTML 中展示最长消息。
- [ ] 原有 CLI 默认行为、Loader 输入和已发布 JSON 字段保持兼容。
- [ ] README 包含 v0.2 示例、指标定义和隐私说明。
- [ ] `gofmt`、`go test ./...`、`go vet ./...`、golangci-lint 全部通过。

## 不在本版本范围

- AI 读取聊天正文、证据引用、LLM Eval 或 Ollama。
- 中文分词、情绪分析、词云和不透明的“亲密度分数”。
- 群聊成员排行、多输入格式、GUI、Web 服务或远程存储。
- 时区命令参数；v0.2 沿用本机本地时区并在输出中明确说明。

## 兼容与发布约束

- 不删除或改变 v0.1 已发布命令和参数的默认行为。
- 不增加运行时外部服务和前端 CDN。
- 优先使用 Go 标准库，不为分位数、日期解析或 JSON 输出增加依赖。
